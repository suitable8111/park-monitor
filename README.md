# 🅿️ 주차 단속 관리 프로그램 (프로토타입)

아파트 관리소 직원을 위한 주차 단속 관리 웹앱입니다.
차량번호를 촬영해 글자를 인식(OCR)하고, **입주민 / 방문객(기간) / 미인식** 차량으로 자동 분류합니다.

## 주요 기능

- 📷 **단속**: 카메라 촬영 또는 사진 업로드 → Tesseract.js OCR로 번호 인식 → 운영자가 확인·수정 → DB 대조 후 분류
  - 🟢 입주민 차량 / 🟢 방문객(기간 유효) / 🟠 방문객(기간 만료·이전) / 🔴 미인식 차량
- 🚗 **차량 관리**: 입주민·방문객 차량 등록/수정/삭제, 동·호수·연락처·방문기간 관리
- 📋 **단속 기록**: 단속 이력 저장 및 조회
- 👤 **사용자 관리**: 관리자 전용, 운영진 계정 생성/권한 관리
- ⚙️ **로그인 권한 분리**
  - **관리자(admin)**: 전체 기능 + 입주민 차량 관리 + 사용자 관리
  - **운영진(operator)**: 단속, 조회, 방문객 차량 등록 (입주민/사용자 관리 불가)

## 기술 스택

- 백엔드: Node.js + Express, `node:sqlite`(내장, 네이티브 빌드 불필요), JWT + bcrypt 인증
- 프론트: 바닐라 JS SPA (모바일 우선), Tesseract.js(브라우저 내 OCR)
- 배포: Render.com (무료 티어)

## 로컬 실행

```bash
npm install
npm start          # http://localhost:3000
# 개발 모드(자동 재시작): npm run dev
```

최초 실행 시 관리자 계정이 자동 생성됩니다: **admin / admin1234**
(로그인 후 `⚙️ 내 계정`에서 비밀번호를 반드시 변경하세요.)

환경변수는 `.env.example` 참고. `JWT_SECRET`, `ADMIN_PASSWORD`는 배포 시 반드시 교체하세요.

> 📷 카메라는 HTTPS 또는 localhost에서만 동작합니다. 배포된 Render 주소는 HTTPS라 정상 작동합니다.

## 배포 (Render)

1. 이 저장소를 GitHub에 푸시
2. [Render](https://render.com) 가입 → **New + → Blueprint** → 저장소 선택
3. `render.yaml`이 자동 인식됨. `ADMIN_PASSWORD`를 안전한 값으로 입력
4. 배포 완료 후 발급된 `https://park-monitor-xxxx.onrender.com` 주소로 접속

> ⚠️ 무료 플랜은 영구 디스크가 없어 재배포/재시작 시 데이터가 초기화됩니다(프로토타입용).
> 데이터를 영구 보존하려면 `render.yaml`의 disk 블록을 활성화하고 유료 플랜으로 전환하세요.
